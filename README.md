# Biggle — Бигги на рабочем столе

Бигги живёт в комнате, парит рядом с другими окнами и помогает вспомнить, на каком шаге ты остановился. Первая демонстрация рассчитана на Windows 10/11 и обычную установку Python 3.10 или новее с Tcl/Tk.

## Запуск на Windows

Распакуй ZIP. В корне распакованного проекта дважды нажми **Start-Biggle.cmd**. Альтернативная команда из корня проекта:

```
py -3 apps/desktop/biggle.py
```

## Демонстрация за минуту

1. В комнате Бигги пьёт чай. Во вкладке «Моё дело» запиши «Подготовить доклад» и шаг «Написать первую фразу». Нажми «Запомнить».
2. Открой «Гардероб», примерь колпак «Звездочёт» и выбери характер «Игривый».
3. Выпусти Бигги на рабочий стол. На Windows область вокруг призрака прозрачная. Перетащи его за персонажа. Коснись один раз — Бигги улыбнётся и подпрыгнет. Три быстрых касания заставят его возмутиться и отлететь. Правая кнопка мыши возвращает его в кресло.
4. Закрой приложение и открой снова. Нажми «На чём я остановился?» — Бигги вспомнит дело и шаг. Очистить их можно кнопкой «Забыть дело и заметку».
5. Для свободного диалога запусти локальный Ollama с установленной текстовой моделью. В поле модели укажи точное имя из `ollama list`, например `qwen3:4b-instruct`. Спроси «Помоги написать первую фразу». Без Ollama доступны комната, память, гардероб и полёт.

Профиль записывается в `%LOCALAPPDATA%/Biggle/profile.json`. При обновлении приложение подхватывает существующий профиль из старой папки. История чата живёт в памяти процесса. При запросе модель получает сохранённое дело, шаг, заметку, характер и до восьми последних сообщений через 127.0.0.1:11434. Камера, запись экрана, аккаунт и платёжный сервис для демо не требуются.

## Как ведёт себя Бигги

| Событие | Реакция |
|---|---|
| В комнате | Парит над сиденьем, держит чашку чая. Можно коснуться самого персонажа. |
| На рабочем столе | Сам выбирает короткие маршруты с плавным разгоном и остановкой. При зажатой кнопке ждёт перетаскивания. |
| Касание | Улыбается, прищуривается и подпрыгивает. Реплика зависит от выбранного характера. |
| Три быстрых касания | Вздрагивает и просит дать ему минутку. На рабочем столе отлетает в сторону. |
| Пять минут без взаимодействия с Бигги | Останавливает самостоятельные перелёты, тихо парит на месте. |
| Десять минут без взаимодействия с Бигги | Возвращается в комнату. Во время таймера фокуса остаётся рядом. |
| Таймер в «Моё дело» | После 25 минут подсказывает сделать перерыв и записать следующий шаг. Таймер работает, пока приложение открыто. |

Долгая память содержит только явно сохранённые дело, шаг, заметку и настройки. Реакции на касание и напоминание работают независимо от языковой модели. Голос, распознавание эмоций камерой, интеграции с другими приложениями и мобильный оверлей относятся к дальнейшим этапам.

## Структура

- `apps/desktop` — самостоятельный клиент на Python/Tk. Тест интерфейса: из этой папки запусти `python -m unittest -v` в графической сессии.
- `services/api` — ранний прототип FastAPI с тестовой авторизацией и эхо-чатом. Десктоп-клиент работает независимо.
- `apps/mobile`, `services/realtime`, `packages/common` — материалы будущих модулей.
- `infra` и `.github/workflows/api-ci.yml` — запуск и проверки раннего API.

Исходный код распространяется по лицензии MIT.
